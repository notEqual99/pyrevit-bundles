# Scientific Calculator (demo)

As a BIM modeler, when you need to calculate Trigo elements (angles, radii, heights, and widths) in Revit you don't need to open others applications or screens. This scientific calculator can perform basic and advanced mathematical operations, including trigonometric functions, logarithmic functions, and inverse functions. It also supports inverse trigonometric functions, inverse logarithmic functions, and inverse inverse functions.
