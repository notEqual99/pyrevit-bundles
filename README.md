# Pyrevit Bundles Add-ins
Develop open-source PyRevit bundle add-ins to provide useful, time-saving tools for BIM users.

## Installation
1. Install pyrevit from their [github repo](https://github.com/pyrevitlabs/pyRevit/releases).
2. Pyrevit Bundles Creator extension folder directory exist at `C:\Users\USER\AppData\Roaming\pyRevit-Master\extensions\pyRevitBundlesCreatorExtension.extension\pyRevit Bundles Creator.tab`.
3. Copy paste extension.panel folder to this directory.
4. You can edit and modify python script in script.py file and can change icon.png file.
